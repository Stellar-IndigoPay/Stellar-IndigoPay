# Stellar IndigoPay Backend

This directory contains the backend codebase for the Stellar IndigoPay platform.

## Services

The backend consists of several key services:
- **CO₂ Verifier**: Validates project carbon offset claims.
- **Indexer**: Monitors Stellar/Soroban ledgers.
- **Push Notifications**: Sends alerts via APNs, FCM, and Expo.
- **Scheduler**: Manages recurring keeper jobs and cron tasks.
